# Approved Visual Reference Manifest

The authoritative visual direction is the approved fantasy mockup family from the design session:

- Fantasy duel screen
- Fantasy four-player Commander screen
- Fantasy six-player Commander dashboard

These references govern black negative space, full-art fantasy player panels, huge life numerals, colored edge accents, immediate poison and CMD access, per-player settings, and the compact utility strip.

The generated reference PNGs are intentionally not treated as shippable production artwork. Final production artwork will be imported only during the approved artwork/theme stage so placeholders cannot silently become final assets.
